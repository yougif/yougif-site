Warudo RhyLive Startup Recovery
================================

기준 환경
- Warudo 0.15.0
- RhyLive
- Windows

파일
- RhyLiveRestartReceiverNode.cs
- RhyLive 시작 복구 - 공유용.json

설치
1. CS 파일을 Warudo_Data\StreamingAssets\Playground 폴더에 복사합니다.
2. Warudo에서 JSON 블루프린트를 가져옵니다.
3. RhyLive 수신기 다시 시작 노드의 Receiver에서 자기 장면의 RhyLive 수신기를 선택합니다.
4. 복구 그래프를 활성화합니다.
5. Warudo를 완전히 종료한 뒤 재실행하여 3~5초 기다립니다.

주의
- 이 파일은 비공식 임시 해결책입니다.
- Warudo/RhyLive 업데이트 후 작동하지 않을 수 있습니다.
- 유선/무선 설정을 강제로 변경하지 않고 현재 설정된 수신기를 다시 시작합니다.
