Warudo RhyLive Startup Recovery
================================

기준 환경
- Warudo 0.15.0
- RhyLive
- Windows

파일
- RhyLiveRestartReceiverNode.cs
- RhyLive 시작 복구 - 공유용.json

설치
1. ZIP 파일의 압축을 풉니다.
2. Warudo 위쪽 Menu → Open Data Folder를 누릅니다.
3. 열린 폴더의 Playground 안에 RhyLiveRestartReceiverNode.cs를 넣고 잠시 기다립니다.
4. Warudo Editor 왼쪽의 Σ 아이콘을 누릅니다.
5. 블루프린트 목록 아래의 ⋯ 메뉴에서 Import Blueprint From File을 선택합니다.
6. 압축을 푼 RhyLive 시작 복구 - 공유용.json을 엽니다.
7. 가져온 그래프에서 RhyLive 수신기 다시 시작 노드를 누릅니다.
8. Receiver에서 현재 장면의 RhyLive 수신기를 선택합니다.
9. 그래프 옆의 눈 아이콘을 켭니다.
10. Warudo를 완전히 종료한 뒤 다시 실행하여 3~5초 기다립니다.

기본 Steam 절대 경로
C:\Program Files (x86)\Steam\steamapps\common\Warudo\Warudo_Data\StreamingAssets\Playground\

공식 Warudo 설명
- 데이터 폴더: https://docs.warudo.app/docs/tutorials/data-folder
- Blueprint 가져오기: https://docs.warudo.app/docs/blueprints/templates/overview

주의
- 이 파일은 비공식 임시 해결책입니다.
- Warudo/RhyLive 업데이트 후 작동하지 않을 수 있습니다.
- 유선/무선 설정을 강제로 변경하지 않고 현재 설정된 수신기를 다시 시작합니다.
